# Manual de usuario de EntregaSegura

## Acceso

1. Abrir la URL de la aplicación.
2. Escribir usuario y contraseña.
3. Seleccionar **Iniciar sesión**.
4. El sistema redirige al panel correspondiente al rol.

## Docente

1. Crear cursos desde **Mis cursos**.
2. Crear grupos desde **Mis grupos** y asignar estudiantes.
3. Crear actividades con título, descripción y fecha límite.
4. Entrar a **Entregas** para consultar los trabajos recibidos.
5. Usar los filtros por curso, actividad, estado, estudiante y fecha.
6. Descargar el resultado como CSV o abrir el reporte imprimible para guardarlo como PDF.
7. Abrir una entrega para revisar evidencias y versiones, y usar **Descargar archivo**
   para guardar el archivo original o cualquiera de sus reentregas.

## Estudiante

1. Entrar a **Mis entregas**.
2. Seleccionar una actividad disponible.
3. Adjuntar el archivo. El repositorio GitHub es opcional: si se proporciona, debe ser
   un enlace público válido y se verifica automáticamente.
4. Revisar el resultado de las cuatro validaciones.
5. Usar **Hacer reentrega** para crear una nueva versión con comentario.

## Mensajes de validación

Una validación aprobada indica que el control se cumplió. Si una validación falla,
la entrega no se guarda y el formulario muestra el motivo para corregirlo.
