# Entrega 1

Esta carpeta contiene el snapshot del proyecto correspondiente al estado
registrado en el commit `7b96e55`, antes de los cambios de la Entrega 2.

Incluye la base inicial de autenticación, usuarios, cursos y grupos.
La aplicación ejecutable se conserva en la raíz del repositorio para evitar
romper sus rutas de Django.

También incluye [Modelo_Entidad_Relacion_EntregaSegura.xlsx], con el modelo
entidad-relación y el diccionario de datos de la estructura base.
