# Seguimiento del proyecto EntregaSegura

Esta carpeta contiene el seguimiento consolidado del proyecto junto con las
entregas 1, 2 y 3.

## Documento incluido

- `Estimacion_Esfuerzo_EntregaSegura_Completada.docx`: estimación de esfuerzo
  completada con el estado real del proyecto, funcionalidades implementadas,
  pruebas, análisis de vulnerabilidades, despliegue, respaldos, pendientes y
  evidencias visuales.

## Estructura del repositorio

- `entrega_1/`: primera entrega.
- `entrega_2/`: segunda entrega.
- `entrega_3/`: tercera entrega.
- `seguimiento/`: consolidado de seguimiento, pruebas y evidencias.
